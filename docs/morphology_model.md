# Морфологічна модель української мови

## Мета
Розробити сервіс, що відмінює українські імена, посади та звання для всіх відмінків та враховує граматичні підказки (рід, істота/неістота, супровідні титули).

## Основні артефакти
- `data/raw/` – сирі джерела (словники, корпуси, списки імен).
- `data/processed/` – очищені та розмічені таблиці (`train/dev/test.csv`).
- `artifacts/` – збережені ваги моделей, словники, статистика експериментів.
- `ml/` – код для обробки даних, навчання та оцінки моделей.

## Початковий план робіт
1. **Збір даних**
   - Офіційні словники (Мін'юст, НАНУ).
   - Публічні реєстри (наприклад, `data.gov.ua`).
   - Перекладацькі ресурси (власні імена, військові звання).
2. **Анотація та нормалізація**
   - Узгодити формати полів: `lemma`, `target_case`, `inflected`, `gender`, `animacy`, `title`.
   - Перевірити специфічні правила (подвоєні приголосні, апостроф, м'який знак).
3. **Базові правила**
   - Побудувати rule-based baseline (напр. через `pymorphy2` + власні винятки).
   - Частотний baseline вже реалізовано у тренувальному пайплайні (`TrainingPipeline`).
4. **ML/AI модель**
   - Розглянути seq2seq (Transformer, LSTM) або morphology-aware architectures.
   - Використати transfer learning із попередньо натренованих моделей (наприклад, mBART, ByT5).
5. **Оцінка**
   - Метрики: exact match, edit distance, case-specific accuracy.
   - Тестові сценарії для імен, по батькові, титулів, абревіатур.
6. **API та інтеграція**
   - REST endpoint (`/api/morphology/inflect/`).
   - Планувати черги для офлайн-навчання та оновлення моделей.

## Наступні кроки
- Заповнити `data/raw/` зразками та згенерувати перші `processed` файли.
- Реалізувати rule-based fallback у `MorphologicalInflector`.
- Інтегрувати справжню ML модель у `ml/training/pipeline.py` та сервісну обгортку.
- Розширити тестове покриття (edge cases, позначення м'якості, апострофи).
